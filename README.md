# Передатчик на ESP32 — проект печатной платы в KiCad

Выполнил: Оськин А.А., группа БМТ2-31М  
Кафедра БМТ-2, МГТУ им. Н.Э. Баумана  
Проверил: Рязанцев П.

Репозиторий: https://github.com/alexeyoskin/peredatchik-esp32

## Задание

Создать проект печатной платы в KiCad. Проект должен содержать:

1. Библиотеку компонентов (УГО и посадочные места). УГО оформлены по ГОСТ, библиотека подключается к проекту как git-сабмодуль, пути к библиотекам относительные.
2. Схему электрическую принципиальную по ГОСТ с рамкой и основной надписью. Важные цепи описаны в классах цепей. У компонентов есть поле `Manufacturer\_Part\_Number` с реальным партномером.
3. Файл печатной платы, разведённый с учётом технологических возможностей завода Резонит (DFMA).
4. Скрипт, который делает проверку ERC и DRC, генерирует gerber-файлы, BOM и pdf-версию схемы.

## Описание устройства

Передатчик собран на модуле ESP32-WROOM-32 и питается от Li-ion аккумулятора 18650.

|Узел|Компоненты|Назначение|
|-|-|-|
|Питание от USB|XS1 (USB Type-C)|5 В для зарядки|
|Заряд аккумулятора|DA1 (TP4054), HL1|контроллер заряда, светодиод показывает заряд|
|Стабилизатор|DA3 (XC6206, LDO 3,3 В)|питание модуля|
|Сброс|DA2 (MAX809), VT2 (AO3400A)|супервизор питания|
|Измерение батареи|R8, R9|делитель, напряжение идёт на АЦП (VBAT\_ADC)|
|Управление|SB1–SB4|кнопки EN, BOOT и две пользовательские (BTN1, BTN2)|
|Звук|HA1 (зуммер), VT1|зуммер с ключом на транзисторе|
|Прошивка|XP1|разъём UART|

Проект выполнен в KiCad 10.

## 1\. Библиотека компонентов

Библиотека лежит в отдельном репозитории `GOST\_ESKD`. В проект она подключена как сабмодуль в папку `lib`:

```
git submodule add https://github.com/alexeyoskin/GOST\_ESKD.git lib
```

Таблицы библиотек проекта используют переменную `${KIPRJMOD}` (папка проекта), поэтому абсолютных путей нет и проект открывается на любом компьютере:

```
(lib (name "GOST\_ESKD")(type "KiCad")(uri "${KIPRJMOD}/lib/GOST\_ESKD.kicad\_sym"))
(lib (name "GOST\_ESKD")(type "KiCad")(uri "${KIPRJMOD}/lib/GOST\_ESKD.pretty"))
```

Путь к рамке в настройках проекта задан так же: `${KIPRJMOD}/lib/GOST\_form1.kicad\_wks`.

### УГО

Все символы нарисованы в миллиметрах, выводы стоят на сетке 2,5 мм, шрифт 2,5 мм. Размеры взяты из ГОСТ:

|Элемент|ГОСТ|Размеры|
|-|-|-|
|Резистор R|2.728|4 × 10 мм|
|Конденсатор C|2.728|обкладки 8 мм, зазор 1,5 мм|
|Светодиод HL|2.730|диод в круге Ø10, стрелки под 45°|
|Транзисторы VT|2.730|круг Ø12 мм|
|Кнопка SB|2.755|разрыв 6 мм, наклон 30°|
|Элемент G|2.742|пластины 8 и 4 мм, зазор 1,5 мм|
|Зуммер HA|2.741|—|
|Микросхемы DA, модуль A|2.743|основное и дополнительные поля, шаг выводов 5 мм|
|Разъёмы XS, XP|2.755|таблица «Конт. / Цепь»|

Позиционные обозначения даны по ГОСТ 2.710. Нумерация выводов совпадает с корпусами. Для SOT-23 разные варианты цоколёвки сделаны отдельными символами (например, `NMOS\_DGS`, `NPN\_CBE`).

### Посадочные места

В `GOST\_ESKD.pretty` собраны все 13 посадочных мест платы. Это корпуса 1206, SOT-23/SOT-23-5, LED 0402, электролиты D5 мм, кнопки, штыревые разъёмы, USB-C GCT USB4135, зуммер и модуль ESP32-WROOM-32. Все компоненты на схеме и на плате ссылаются на библиотеку `GOST\_ESKD`.

## 2\. Схема электрическая принципиальная

Схема нарисована на одном листе формата А3. Рамка `GOST\_form1.kicad\_wks` сделана по ГОСТ 2.301 и ГОСТ 2.104 (форма 1):

* поля 20/5/5/5 мм;
* основная надпись 185 × 55 мм;
* дополнительные графы 19–23 и 26.

Поля надписи заполняются в *Файл → Параметры страницы*. Обозначение схемы: БИГЕ.941239.001 Э3.

!\[Схема электрическая принципиальная](docs/schematic.png)

### Классы цепей

Важные цепи распределены по классам цепей (*Параметры схемы → Классы цепей*) и выделены цветом.

|Класс|Цвет|Цепи|
|-|-|-|
|Power|красный|/VBUS, /VBAT|
|Power\_3V3|оранжевый|/+3V3|
|GND|синий|GND, /GND\_BAT|
|Signal|зелёный|/UART\_TX, /UART\_RX, /ESP\_EN, /BOOT, /RESET\_N, /BTN1, /BTN2, /BUZZER, /VBAT\_ADC, /CHRG|

Цепи названы локальными метками, поэтому KiCad добавляет к их именам «/». С этим префиксом записаны и шаблоны классов.

## 3\. Печатная плата

!\[Печатная плата, верхний слой](docs/pcb.png)

|Параметр|Значение|
|-|-|
|Размер платы|56,5 × 58 мм|
|Число слоёв|2|
|Толщина|1,6 мм|
|Мин. ширина проводника|0,2 мм (выводы ESP32), основные трассы 0,4 мм|
|Мин. зазор|0,2 мм|
|Переходные отверстия|0,6 / 0,3 мм|
|Мин. диаметр отверстия|0,2 мм|
|Мин. гарантийный поясок|0,1 мм|
|Зазор медь – край платы|0,5 мм|
|Крепёжные отверстия|4 × Ø3 мм по углам|
|Земля|полигоны GND на обоих слоях|

Нормы взяты с запасом относительно стандартных возможностей завода Резонит. Плату можно заказать как обычную двухслойную, без дополнительных опций.

Что сделано для технологичности (DFMA):

* все компоненты стоят на одной стороне (верхний слой). Так плату можно собрать за один проход;
* пассивные компоненты в основном одного корпуса 1206, ручная пайка тоже возможна;
* под антенной ESP32 оставлена зона без меди, модуль выходит антенной к краю платы;
* переходных отверстий всего 4, остальная разводка на верхнем слое;
* полигоны земли подключены к площадкам через термобарьеры;
* позиционные обозначения на шелкографии не заходят на площадки;
* разъёмы USB, UART и кнопки стоят у краёв платы.

Результат DRC: 0 ошибок, 0 неразведённых соединений, плата соответствует схеме.

## 4\. Скрипт

Скрипт `kicad\_project\_processing.bat` (для Windows) и `kicad\_project\_processing.sh` (для Linux) лежат в корне проекта и запускаются оттуда же. Имя проекта скрипт берёт из файла `.kicad\_pro`, все пути относительные, результаты складываются в папку `output/`.

|Шаг|Команда|Результат|
|-|-|-|
|ERC|`kicad-cli sch erc --severity-error --exit-code-violations`|`output/erc\_report.rpt`|
|DRC с проверкой соответствия схеме|`kicad-cli pcb drc --schematic-parity --refill-zones --severity-error --exit-code-violations`|`output/drc\_report.rpt`|
|PDF схемы|`kicad-cli sch export pdf -b`|`output/<проект>\_schematic.pdf`|
|BOM|`kicad-cli sch export bom` (поля: позиция, номинал, корпус, партномер, кол-во)|`output/<проект>\_BOM.csv`|
|Gerber|`kicad-cli pcb export gerbers` (слои Cu, Paste, Mask, Silkscreen, Edge.Cuts)|`output/gerbers/`|
|Сверловка|`kicad-cli pcb export drill --excellon-separate-th`|`output/gerbers/`|
|Архив для завода|zip папки `gerbers`|`output/<проект>\_gerbers.zip`|
|3D-модель|`kicad-cli pcb export step`|`output/<проект>.step`|

Если ERC или DRC находит ошибки, скрипт сообщает об этом и завершается с кодом 1.
